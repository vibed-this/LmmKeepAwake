# Tray icon source

The tray icon design was selected to match the Windows 11 visual language. Icons8 provides matching **Light On** and **Light Off** references in its Windows 11 Color style:

- https://icons8.com/icon/kDPHHp80u2xF/light-on
- https://icons8.com/icon/pnAzBmKhMsHa/light-off

LmmKeepAwake uses a small, custom-rendered bulb icon based on the same visual concept rather than bundling the third-party raster artwork. This keeps the executable self-contained and suitable for a 16×16/32×32 Windows notification-area icon.
